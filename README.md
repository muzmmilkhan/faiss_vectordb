# FAISS Vector Database

A small, notebook-based example of semantic search with [FAISS](https://github.com/facebookresearch/faiss). The project:

1. Splits source text into overlapping word-based chunks.
2. Generates embeddings with `text-embedding-3-small`.
3. Stores the embeddings in a FAISS `IndexFlatL2` index.
4. Searches the index for the chunks most similar to a query.
5. Saves the index to `faiss_index.faiss`.

The sample data in the notebook is a short biography of Sudhanshu and the iNeuron education platform.

## Requirements

- Python 3.12 or newer
- An `EURI_API_KEY`
- [`uv`](https://docs.astral.sh/uv/) for environment and dependency management

## Setup

Clone the repository and install the locked dependencies:

```bash
uv sync
```

Create a `.env` file in the project root:

```dotenv
EURI_API_KEY=your_api_key_here
```

Do not commit `.env` or expose your API key.

## Run the notebook

Start Jupyter through the project environment:

```bash
uv run jupyter notebook faiss.ipynb
```

Run the cells from top to bottom. The embedding cell uses the EURI OpenAI-compatible endpoint:

```text
https://api.euron.one/api/v1/euri
```

The notebook creates six overlapping chunks by default, generates embeddings, builds the FAISS index, and writes the index file to:

```text
faiss_index.faiss
```

## How it works

Text is chunked into groups of 50 words with an overlap of 10 words:

```python
chunked_data = chunk_text(data, chunk_size=50, overlap=10)
```

Embeddings are generated in one batch:

```python
response = client.embeddings.create(
    model="text-embedding-3-small",
    input=chunked_data,
)
```

The vectors are indexed with Euclidean distance:

```python
faiss_index = faiss.IndexFlatL2(embeddings.shape[1])
faiss_index.add(embeddings)
```

To search, embed a query using the same model and retrieve the five nearest vectors:

```python
distances, indices = faiss_index.search(query_embedding, k=5)
```

The returned indices correspond to entries in `chunked_data`.

## Notes

- The saved FAISS index contains vectors only; the original text chunks are not stored in it. Keep the chunk list or other metadata alongside the index in a production application.
- Queries must use embeddings with the same dimensionality and compatible model as the indexed vectors.
- Re-run the notebook after changing the source text or chunking settings so that the persisted index stays in sync.
